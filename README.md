# Big Fish Eats Small Fish

A little browser game I made. You're a fish. Eat smaller fish, don't get eaten. That's it.

## Play

Just open `index.html`. No build, no install, no nothing.

## How it was made

Codex++ running against DeepSeek-V4-Flash wrote most of the code. I did the prompting, testing, and the annoying parts like collision tuning. The whole thing is vanilla JS + canvas, no libraries, no build step.
